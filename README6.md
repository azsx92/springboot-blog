## 4. OAuth2 실행 테스트
### 01 단계 
- 스프링 부트 애플리케이션을 실행한 다음 http://localhost:8080/loginb에 접속하고 [구글로 로그인 하기] 클릭한다.
- 버튼을 클릭하면 구글 로그인 페이지가 나타날 것 이다.
- 이것이 바로 OAuth2를 이용해 로그인하는 것이다.
- ![스크린샷 2025-04-21 오후 8.48.21.png](..%2F..%2F..%2FDesktop%2F%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7%202025-04-21%20%EC%98%A4%ED%9B%84%208.48.21.png)
- ![계정선택.png](..%2F..%2F..%2FDesktop%2F%EA%B3%84%EC%A0%95%EC%84%A0%ED%83%9D.png)

### 02단계
- 로그인이 완료되면 /articles로 리다이렉트되며, 쿼리 파라미터에 token , 액세스 토큰을 요청 헤더로 전달한다.
- 그 뒤에 브라우저의 메뉴에서 [도구 더보기] -> [개발자 도구]를 클릭해 개발자 도구를 열어 [Application]dml [Local Storage]를 클릭하면 스프링 부트 애플리케이션으로부터 전달받은 액세스 토큰을 저장한다는 것을 확인 할 수 있다.
- ![토큰 생성시 등록 완료.png](..%2F..%2F..%2FDesktop%2F%ED%86%A0%ED%81%B0%20%EC%83%9D%EC%84%B1%EC%8B%9C%20%EB%93%B1%EB%A1%9D%20%EC%99%84%EB%A3%8C.png)
- 리프레시 토큰도 잘 있나 확인 해볼 수 있다.
- [Cookies]를 누르면 리프레시 토큰도 잘 저장 되어 있다.
- ![리프레시 토큰.png](..%2F..%2F..%2FDesktop%2F%EB%A6%AC%ED%94%84%EB%A0%88%EC%8B%9C%20%ED%86%A0%ED%81%B0.png)

### 03 단계
- /new-article로 이동해 클을 등록해 본다. 글 등록 시 액세스 토큰이 유효하므로 인증 필터를 통과하고 글도 잘 등록 된다.
- ![토큰 생성시 등록 완료.png](..%2F..%2F..%2FDesktop%2F%ED%86%A0%ED%81%B0%20%EC%83%9D%EC%84%B1%EC%8B%9C%20%EB%93%B1%EB%A1%9D%20%EC%99%84%EB%A3%8C.png)
- ![등록완료 .png](..%2F..%2F..%2FDesktop%2F%EB%93%B1%EB%A1%9D%EC%99%84%EB%A3%8C%20.png)

### 04 단계
- 액세스 토큰이 만료되거나 삭제되면 어떤 API 요청 흐름이 발생하는지 알기 위해 [개발자 도구]의 [Application -> Local Storage]에 들어간 후 access_token을 우클릭하고 [Delete]를 눌러 값을 삭제해 본다.
- ![에쎄신토큰 제거.png](..%2F..%2F..%2FDesktop%2F%EC%97%90%EC%8E%84%EC%8B%A0%ED%86%A0%ED%81%B0%20%EC%A0%9C%EA%B1%B0.png)
- ![어쎼신토큰 제거시 등록실패.png](..%2F..%2F..%2FDesktop%2F%EC%96%B4%EC%8E%BC%EC%8B%A0%ED%86%A0%ED%81%B0%20%EC%A0%9C%EA%B1%B0%EC%8B%9C%20%EB%93%B1%EB%A1%9D%EC%8B%A4%ED%8C%A8.png)

### 05 단계
- 다시 /new-article류ㅗ 이동한 뒤 글 등록을 시도해 본다. 액세스 토큰을 유효하지 않지만 리프레시 토큰이 있으므로 /token API를 호출해 새 액세스 토큰을 발급받아 인증을 다시 요청해 인증 필터를 통과해 글이 잘 등록된다.
- ![스크린샷 2025-04-21 오후 9.39.54.png](..%2F..%2F..%2FDesktop%2F%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7%202025-04-21%20%EC%98%A4%ED%9B%84%209.39.54.png)

### 06 단계 
- 이번에는 내가 작성하지 않은 글을 수정하거나 삭제하면 어떻게 되는지 확인해 본다.
- 내가 작성한 글이 아닌 글을 삭제하려고 하면 실패 메시지가 나오고 , 삭제가 되지 않는다. 이는 수정도 마찬가지다.
